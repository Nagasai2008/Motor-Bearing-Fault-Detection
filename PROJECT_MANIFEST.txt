Member 4 (Frontend Web Dashboard & UI Lead)

================================================================================
                            PROJECT OVERVIEW
================================================================================

This is a complete, production-grade web dashboard for real-time monitoring
of motor bearing health using FFT spectral analysis and anomaly detection.

🎯 PRIMARY OBJECTIVE: Provide a professional, responsive web interface that
   displays real-time bearing fault detection data from an ESP32 microcontroller
   with INMP441 MEMS microphone input.

📊 TECHNOLOGY STACK:
   • Frontend: HTML5, CSS3, Vanilla JavaScript (ES6+)
   • Visualization: Chart.js 4.4.0 (CDN)
   • Communication: WebSocket (JSON)
   • Simulation: Python 3 + asyncio + websockets
   • Compatibility: Chrome 90+, Firefox 88+, Safari 14+, Edge 90+

                        QUICK REFERENCE - KEY SPECS
================================================================================

WEBSERVER SETUP:
  Python 3:    python -m http.server 8000
  Node.js:     npx http-server -p 8000
  VS Code:     Right-click index.html → Open with Live Server

WEBSOCKET CONNECTION:
  Default URL: ws://localhost:8080
  For ESP32:   ws://192.168.1.XXX:8080
  Auto-reconnect with exponential backoff

DATA RATES:
  Telemetry:   Every 500ms
  Chart update: No animation (real-time smooth)
  Event log:   Keeps last 100 entries
  Data export: Instant CSV generation

TELEMETRY PACKET SIZE:
  256 elements × 4 bytes (float) = 1 KB per packet
  Every 500ms = ~2 KB/second
  Bandwidth efficient for WiFi

FREQUENCY RESOLUTION:
  Sample rate: 16,000 Hz
  FFT size: 512 samples (32ms window)
  Frequency bins: 256 (0-8000 Hz)
  Resolution: ~31 Hz per bin

STATUS LOGIC:
  peakFreq 0-3000 Hz    → HEALTHY (green)
  peakFreq 3000-8000 Hz → WARNING (orange)
  anomalyScore >= 80%   → CRITICAL (red)
